# Navigation icons

Local SVGs downloaded from the [Iconify API](https://api.iconify.design/tabler.json?icons=menu-2,x):

- `menu-2.svg`: `tabler:menu-2`, the three-line menu icon.
- `x.svg`: `tabler:x`, the close icon.

Both come from [Tabler Icons](https://github.com/tabler/tabler-icons), licensed under MIT, copyright 2020–2026 Paweł Kuna. The full MIT notice is included inside each SVG and is also available in [the existing license file](../technologies/TABLER-LICENSE.txt).

Original paths and `fill="none"` are preserved. CSS masks use the shared `--text: #fefefe` token, so the monochrome icons remain visible in the dark header. No runtime icon service is required.
