# Technology icons

These SVGs were retrieved from the [Iconify API](https://iconify.design/docs/api/) for the About page. They are bundled locally; the browser makes no icon CDN requests. Original SVG geometry is preserved. CSS masks render these monochrome icons in `#fefefe` using the site's text token.

The pre-existing `../html.svg` and `../css.svg` remain the HTML5/CSS3 marks. They are not duplicated or modified here.
